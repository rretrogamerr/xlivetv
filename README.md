# xLiveTV

웨이브, 티빙의 실시간 채널을 시청할 수 있는 안드로이드TV 앱

## 다운로드

- [xlivetv.apk](https://github.com/rretrogamerr/xlivetv/releases)

## 설치

다운로드한 APK를 Android TV 또는 Google TV 기기로 옮긴 뒤 파일 관리자에서 실행합니다. `알 수 없는 앱 설치` 권한 요청이 표시되면 해당 파일 관리자를 허용합니다.

### 설치 버튼을 눌러도 반응이 없는 경우

파일 관리자에서 `설치`를 눌러도 진행되지 않고 권한 요청 화면도 나타나지 않으면, USB 디버깅과 ADB를 이용해 한 번 설치해 볼 수 있습니다. ADB는 필수 설치 방식이 아니라 설치 가능 여부를 확인하고 막힌 설치 흐름을 우회하기 위한 방법입니다.

1. 기기에서 `설정 → 시스템 → 정보 → Android TV OS 빌드`를 7번 눌러 개발자 모드를 활성화합니다.
2. `설정 → 시스템 → 개발자 옵션`에서 `USB 디버깅`을 켭니다.
3. 데이터 전송을 지원하는 USB 케이블로 기기와 PC를 연결합니다.
4. 기기에 디버깅 허용 팝업이 표시되면 해당 PC를 허용합니다.
5. PC에서 기기가 연결되었는지 확인하고 APK를 설치합니다.

   ```bash
   adb devices
   adb install -r "/path/to/xlivetv.apk"
   ```

`adb devices`에 기기가 표시되고 설치 결과가 `Success`라면 APK 사이드로딩 자체가 차단된 것은 아닙니다. 이후 파일 관리자에서 APK를 다시 열었을 때 `알 수 없는 앱 설치` 권한 요청이 나타나면 해당 파일 관리자를 허용하세요. 해당 권한이 유지되는 동안에는 ADB 없이 파일 관리자에서 직접 설치하거나 업데이트할 수 있습니다.

개발자 모드는 ADB 연결에 필요한 `USB 디버깅` 설정을 활성화하기 위한 것이며, 개발자 모드나 ADB 설치가 파일 관리자의 설치 권한을 자동으로 부여하는 것은 아닙니다. 권한 화면이 뒤늦게 나타난 정확한 원인은 기기나 시스템 상태에 따라 다를 수 있습니다.

기기가 표시되지 않으면 USB 디버깅 설정, 기기의 디버깅 허용 팝업, USB 케이블의 데이터 전송 지원 여부를 확인한 뒤 다음 명령으로 ADB를 재시작해 보세요.

```bash
adb kill-server
adb start-server
adb devices
```

## 유의사항

- 웨이브, 티빙에 실시간 채널을 시청할 수 있는 적절한 권한의 유료 상품에 가입되어있어야 합니다. (각 서비스 별 로그인 후 시청 가능)
- 웨이브, 티빙과 아무런 관계가 없는 앱으로, 사전 고지 없이 배포 및 서비스가 중단될 수 있습니다.

## 안내사항

- 웨이브, 티빙 로그인 관련 비밀번호를 저장하거나 수집하지 않습니다.
- Firebase Analytics를 활용하여 사용성 개선을 위한 통계 데이터 외에 개인정보(ID, 비밀번호 등)를 수집하지 않습니다.
